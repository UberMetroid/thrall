[01] Option B Per-Folder Sync (Zero Dotfiles)

Never syncs ~/.config or hidden dotfiles. Every user's top-level folders under /users/<username>/<Folder> are provisioned as isolated Syncthing folders across the fleet:

  • Default 8 XDG desktop folders: Desktop, Documents, Downloads, Music, Pictures, Public, Templates, Videos.
  • Users can create or delete custom top-level folders directly in Tab 1 (Files).
  • Admins can create, delete, and assign LDAP ACLs to top-level organizational shared folders (/shared/<Folder>) in Tab 4 (Access Control).

[02] Two-Way Zero-Trust Handshake

Clients never expose their REST API. Instead:

  • Step 1 (Client → Gateway): The user adds the primary THRALL Gateway Device ID in their local Syncthing GUI with [x] Introducer and [x] Auto Accept enabled.
  • Step 2 (Gateway → Client): The user pastes their 56-character Device ID into THRALL. THRALL strips formatting noise, verifies all 4 Base32 Luhn mod 32 check digits, auto-assigns a device label (dev-1-<short_id>), and pushes folder grants across every regional node.

[03] Path-Jailed Explorer & Live Mesh Physics

Built-in dark-mode file explorer with strict symlink-escape and dotfile protection:

  • Browse, create, and delete files or subfolders inside personal vaults (personal:<Folder>) and shared team vaults (shared:<Folder>).
  • Toggle instant read-only capability links (/s/<token>) and track per-workstation folder acceptance badges.
  • Zero-SSH TCP :22000 RTT ping-scaled rotating server spotlights, client workstation mini-node orbiters, and 3 dedicated per-node telemetry tickers.
